# Domain Docs

Chunks-LMS uses a single domain context.

## Before exploring

Read:

- `CONTEXT.md` at the repository root;
- relevant decisions under `docs/adr/`;
- `docs/architecture/chunks-lms-architecture-review.md` when work affects system shape or product scope.

Use the glossary vocabulary in issues, tests, specifications, and implementation. If a needed concept is missing or conflicts with existing language, resolve it through domain modeling rather than silently introducing a synonym.

If proposed work conflicts with an ADR, surface the conflict explicitly before changing direction.
