# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues in `genshai-11/Chunks-LMS`.

## Conventions

- Create, read, comment on, label, and close work through GitHub Issues.
- Infer the repository from the configured `origin` remote.
- When a skill says “publish to the issue tracker,” create a GitHub issue.
- When a skill says “fetch the relevant ticket,” retrieve the issue body, labels, and comments.
- Use native GitHub sub-issues and dependencies where available; otherwise record `Blocked by: #<number>` explicitly.

## Pull requests as a triage surface

**PRs as a request surface: no.**

GitHub shares one number space across issues and pull requests; resolve ambiguous references before acting.
