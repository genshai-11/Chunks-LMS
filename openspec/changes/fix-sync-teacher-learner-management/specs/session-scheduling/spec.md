## ADDED Requirements

### Requirement: Selected Learner observation ordering

The system SHALL support a selected Learner as the first round-robin assignment while retaining a Class-scoped Learning Session.

#### Scenario: Reordered learner list

- **WHEN** a Teacher starts a Learning Session from a Learner profile
- **THEN** the selected Learner is first and all active enrolled Learners remain in the observation rotation
